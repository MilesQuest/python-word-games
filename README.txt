Hello!

These are some word games I have written in Python 3.

To play them, I recommend opening the launcher ("main.py")

If you want to modify them for your personal use, go ahead!

Also, each game depends on a file named "dictionary.txt". Since it is in the public domain, I used the ENABLE1 dictionary. You may replace it with any list of words as long as it is titled "dictionary.txt"

P.S: enable1 is a complete, unfiltered English wordbook and may include rude terms in its outputs.
